# Shopify-sectie: Video reviews

`sections/video-reviews.liquid` is een carousel met klantvideo's (try-on / outfit reviews).
De middelste video speelt automatisch zonder geluid, de video's ernaast zijn kleiner en gepauzeerd.
Er zijn knoppen voor geluid en afspelen/pauzeren, pijlen, swipe op mobiel, en per video een naam en sterren.

## Installatie
1. Shopify admin → **Online Store → Themes** → bij je thema **⋯ → Edit code**.
2. Map **Sections** → **Add a new section** → naam `video-reviews` (type Liquid).
3. Vervang alle inhoud door de inhoud van `sections/video-reviews.liquid` en klik **Save**.
4. **Customize** → open de productpagina-template → **Add section** → **Video reviews**.
5. Klik elke video-block aan → upload een video (staand formaat, liefst 10–30 sec) → vul naam en sterren in.

Werkt met elk Online Store 2.0-thema (Dawn, Sense, Impulse, enz.).
